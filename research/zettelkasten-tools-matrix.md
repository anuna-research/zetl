## Tool Categories

### Full-featured PKM Platforms
Tools that aim to be comprehensive knowledge management systems:
- **SiYuan** - Block-level WYSIWYG, E2E encryption, self-hosted sync
- **Logseq** - Outliner-first, journal-centric, strong plugin ecosystem
- **TriliumNext** - Hierarchical notes, rich scripting, web clipper
- **Joplin** - Cross-platform, E2E encryption, extensive sync options

### Editor-integrated (VS Code / Emacs / Vim)
Tools that extend existing editors:
- **Foam** - VS Code, Roam-inspired, Git-backed
- **Dendron** - VS Code, hierarchical schema system (unmaintained)
- **Memo** - VS Code, minimal bidirectional linking
- **Org-roam** - Emacs, Org-mode based, most mature in category
- **vim-zettel** - Vim, VimWiki-based
- **iwe** - Editor-agnostic via LSP (Neovim, Helix, VS Code, Zed)

### CLI-first
Tools designed for terminal workflows:
- **nb** - Bash-based, bookmarking, encryption, Git versioning
- **zk** - Go, LSP server, plain text focused
- **Neuron** - Haskell, static site generation (superseded by Emanote)

### Static Site Generators / Publishing
Tools focused on publishing Zettelkasten content:
- **Emanote** - Haskell, structured views of plain-text notes
- **Zettlr** - Academic focus, Pandoc integration

### Desktop-native
Traditional desktop applications:
- **Zettlr** - Electron, academic writing focus
- **QOwnNotes** - Qt/C++, Nextcloud integration
- **Zkn3** - Java, faithful to Luhmann's original method
- **Standard Notes** - Zero-knowledge encryption focus
- **TiddlyWiki** - Single HTML file, highly extensible

### Workspace / Notion alternatives
Broader workspace tools with some Zettelkasten features:
- **AppFlowy** - Flutter/Rust, AI-enhanced, real-time collaboration

### AI-enhanced
Tools incorporating AI/LLM features:
- **Rocketnotes** - LLM integration for semantic search
- **SiYuan** - AI writing assistant features
