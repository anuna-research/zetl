# Obsidian

Obsidian is a Markdown-based [[Knowledge Management]] tool that implements [[Bidirectional Links]] via `[[wikilink]]` syntax. It stores notes as plain files on the local filesystem.

## Key Features

- **Graph view** — visualizes the [[Knowledge Graph]] of all notes
- **Backlinks panel** — shows all notes linking to the current note
- **Local-first** — all data stored as Markdown files (no vendor lock-in)
- **Plugin ecosystem** — extensible via community plugins
- **Templates** — for consistent note creation

## Zettelkasten Workflow in Obsidian

1. Create [[Atomic Notes]] with descriptive titles
2. Link to related notes with `[[wikilinks]]`
3. Use the backlinks panel to discover connections
4. Create [[Map of Content]] notes for navigation
5. Use `zetl check` to find orphans and dead links
