# Logseq

Logseq is an open-source, outliner-based [[Knowledge Management]] tool. Like [[Obsidian]], it supports [[Bidirectional Links]] via `[[wikilink]]` syntax and stores data as local Markdown files.

## Key Differences from Obsidian

- **Block-level linking** — Logseq treats blocks (bullet points) as first-class units, enabling finer-grained linking than page-level [[Bidirectional Links]]
- **Journal-first workflow** — daily journal pages are the default entry point
- **Outliner interface** — all content is structured as nested bullet points

## Zettelkasten in Logseq

Logseq's block-level references make it natural to practice the [[Zettelkasten]] method at a granular level. Each block can function as an [[Atomic Notes|atomic note]], linked to other blocks or pages.

However, the outliner format can make it harder to write long-form [[Literature Notes]].
