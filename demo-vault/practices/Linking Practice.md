# Linking Practice

Good linking is the most important skill in a [[Zettelkasten]]. Without deliberate linking, you end up with a collection of isolated notes instead of a [[Knowledge Graph]].

## When to Create a Link

Ask yourself:
- "Does this note relate to an existing concept?" → Link it
- "Would someone reading that note benefit from knowing about this?" → Link it
- "Is this a different perspective on an existing idea?" → Link it and note the contrast

## Types of Links

1. **Contextual links** — woven into the text: "This relates to [[Emergent Structure]]"
2. **See-also links** — listed at the bottom for related concepts
3. **MOC references** — linking from a [[Map of Content]] to its children
4. **Source links** — connecting [[Atomic Notes]] to their [[Literature Notes]]

## Anti-patterns

- Linking everything to everything (low signal-to-noise)
- Only linking at the "See also" section (misses contextual meaning)
- Never reviewing backlinks (missing half the value of [[Bidirectional Links]])
