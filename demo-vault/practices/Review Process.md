# Review Process

Regular review is essential to maintaining a healthy [[Zettelkasten]].

## Weekly Review

1. Process [[Daily Note Practice]] captures into [[Atomic Notes]]
2. Check for [[broken link targets
3. Review orphan notes — should they be linked or deleted?
4. Add notes to relevant [[Map of Content]] pages
5. Review [[]] empty links that need filling in

## Monthly Review

- Run `zetl stats` to track growth
- Run `zetl check` to find dead links and orphans
- Look at the [[Knowledge Graph]] for disconnected clusters
- Reflect on what topics are growing vs. stagnant

See also: [[Linking Practice]], [[Knowledge Management]]
