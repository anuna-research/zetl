# Daily Note Practice

A daily note practice involves creating a new note each day to capture thoughts, tasks, and fleeting ideas. Both [[Obsidian]] and [[Logseq]] support this with daily note templates.

## Connection to Zettelkasten

Daily notes serve as an inbox for the [[Zettelkasten]]. During a review session, you:

1. Review the day's captures
2. Extract ideas into [[Atomic Notes]]
3. Link them to existing notes via [[Bidirectional Links]]
4. Discard or archive the daily note

Without this processing step, daily notes become a graveyard of unprocessed thoughts (see the Collector's Fallacy in [[Knowledge Management]]).

## Tips

- Keep daily notes lightweight
- Use tags or links to connect to ongoing projects
- Process within 24 hours (see [[Elaborative Encoding]])
- Don't worry about perfection — daily notes are ephemeral
