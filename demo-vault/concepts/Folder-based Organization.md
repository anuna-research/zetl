# Folder-based Organization

Folder-based organization is the traditional approach to [[Knowledge Management]]: files are placed into hierarchical directories.

## Limitations

- **Single classification** — a file can only exist in one folder
- **Rigid hierarchy** — reorganization is expensive
- **Context loss** — related files in different folders become invisible to each other
- **Scaling problems** — deep folder trees become hard to navigate

## When It Works

Folders are fine for:
- Project-specific files (contracts, deliverables)
- Archival storage with clear categories
- Compliance/regulatory documentation

## The Alternative

The [[Zettelkasten]] approach replaces folders with [[Bidirectional Links]] and [[Emergent Structure]]. Notes don't "live" anywhere — they exist in a flat namespace and gain context through connections.

Tools like [[Obsidian]] still support folders but encourage link-based navigation over folder-based filing.
