# Functional Programming

Functional programming is a paradigm that treats computation as the evaluation of mathematical functions.

## Connection to Zettelkasten

Not directly related, but [[Atomic Notes]] share the principle of composability with FP:
small, pure functions compose into larger systems, just as atomic notes compose into a [[Knowledge Graph]].
