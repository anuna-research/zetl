# Atomic Notes

An atomic note captures exactly one idea, concept, or insight. This is a core principle of the [[Zettelkasten]] method.

## Why Atomicity Matters

When notes are atomic, they become reusable building blocks. A note about "recursion" can link to notes about [[Functional Programming]], [[Data Structures]], or [[Mathematical Induction]] without any of those contexts dominating.

Non-atomic notes (e.g., "meeting notes from Tuesday") are hard to link because they contain multiple unrelated ideas.

## Guidelines

- One idea per note
- The title should summarize the idea
- The body should be self-contained (understandable without context)
- Link generously to related [[Atomic Notes]] via [[Bidirectional Links]]
- Prefer your own words over direct quotes (see [[Elaborative Encoding]])

## Contrast with Literature Notes

[[Literature Notes]] capture ideas from a source. Atomic notes are the distilled, rewritten insights derived from literature notes. The flow is:

1. Read a source → create [[Literature Notes]]
2. Distill insights → create Atomic Notes
3. Link to existing notes → grow the [[Zettelkasten]]
