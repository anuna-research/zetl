# Map of Content

A Map of Content (MOC) is a note that serves as an index or entry point to a cluster of related [[Atomic Notes]]. MOCs are a form of [[Emergent Structure]] — you create them when you notice a group of notes forming a coherent topic.

## When to Create a MOC

Nick Milo suggests creating a MOC when a topic has accumulated enough notes (roughly 5-10+) that you need a guide to navigate them.

## Example

A "Zettelkasten MOC" might link to:

- [[Zettelkasten]] — the core concept
- [[Atomic Notes]] — the unit of knowledge
- [[Bidirectional Links]] — the connective mechanism
- [[Niklas Luhmann]] — the originator
- [[Luhmann's Slip Box]] — the physical implementation
- [[Knowledge Graph]] — the emergent structure
- [[Evergreen Notes]] — a modern restatement

## MOCs vs. Folders

Unlike [[Folder-based Organization]], a note can appear in multiple MOCs. An MOC about "research methods" and one about "writing workflow" can both reference the same notes without conflict.
