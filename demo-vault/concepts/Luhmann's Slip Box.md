# Luhmann's Slip Box

[[Niklas Luhmann]]'s physical [[Zettelkasten]] consisted of wooden furniture containing roughly 90,000 handwritten index cards (A6 size).

## Numbering System

Cards were numbered with an alternating numeric-alphabetic scheme:

- `1` → `1a` → `1a1` → `1a1a` ...
- `1b` (a branching idea from card 1)
- `2` (a new top-level sequence)

This allowed inserting new cards between existing ones — creating a tree-like structure that functioned similarly to [[Bidirectional Links]].

## Two Boxes

Luhmann maintained two separate boxes:

1. **Reference box** — [[Literature Notes]] with bibliographic information
2. **Main box** — [[Atomic Notes]] with ideas and arguments

The main box was the [[Zettelkasten]] proper. Cards in the main box referenced each other by number and referenced literature notes for sources.

## Digital Equivalents

Modern tools like [[Obsidian]] and [[Logseq]] replicate this system digitally, replacing numbered cards with named files and manual cross-references with [[Bidirectional Links]].

The key insight that transfers: the value is in the connections, not the individual cards.
