# Second Brain

The "Second Brain" is a [[Knowledge Management]] framework by Tiago Forte, based on the CODE methodology:

1. **Capture** — save interesting information
2. **Organize** — sort by actionability (PARA: Projects, Areas, Resources, Archive)
3. **Distill** — apply [[Progressive Summarization]]
4. **Express** — create output from your collected knowledge

## Relationship to Zettelkasten

The Second Brain and [[Zettelkasten]] share the goal of externalizing knowledge, but differ in approach:

| Aspect | Second Brain | Zettelkasten |
|--------|-------------|--------------|
| Organization | [[Folder-based Organization]] (PARA) | [[Bidirectional Links]] |
| Unit | Project-oriented notes | [[Atomic Notes]] |
| Structure | Top-down (folders) | Bottom-up ([[Emergent Structure]]) |
| Tools | [[Notion]], Evernote | [[Obsidian]], [[Logseq]] |

Many practitioners combine both: PARA folders for actionable projects, Zettelkasten for long-term knowledge.
