{# themes/default/_graph_vendor.html — SPEC-028 graph vendor lazy loader. Defines `window.__zetlEnsureGraph`, the singleton-Promise that lazy-injects graphology + graphology-layout-forceatlas2 + sigma (~150 kB) only when the reader actually opens the graph (docked launcher click, navbar toggle, or landing on the full-page /_graph route). Resolves a single Promise so repeat callers share the existing load. Lives as a partial (not inlined in base.html) because the graph widget is core zetl functionality that must keep working when a user picks a non-default theme. The 3-tier template loader resolves `_graph_vendor.html` from the bundled `default` theme as a fallback when the active theme doesn't ship its own — so any base.html that includes this partial inherits a working loader for free, regardless of theme. The trailing IIFE handles the full-page /_graph route's auto-trigger (the docked-widget controller in the default theme's base.html does this for the docked widget separately). Pulling it in here means non-default themes' vault_graph renders kick off the loader without each theme needing to copy the wiring. #}
