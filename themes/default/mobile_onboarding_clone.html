SSH is recommended. Once you've added the public key above to your git host, SSH URLs like git@github.com:owner/repo.git work for clone and ongoing pull/push with no extra setup. HTTPS URLs of public repos also work; private HTTPS needs a PAT (advanced).

💡 Looks like an HTTPS URL. Want to instead? It's — your existing SSH key works.
Advanced: private HTTPS (personal access token)

Prefer SSH — it's auto-configured by this app. Only fall back to a PAT if your git host blocks SSH or you have a specific HTTPS-only constraint. The PAT is used once for the clone and never written to disk; pull / push will need it re-entered until v0.1.x adds keychain storage for HTTPS credentials.

Advanced: use my desktop's BIP39 seed phrase instead

Pasting your 12-word recovery phrase from zetl derive-ssh-key --mnemonic on desktop will replace the auto-generated per-device key above with the deterministic one derived from your seed. Only do this if you want this phone to share an identity with your desktop. The seed is never written to disk.
